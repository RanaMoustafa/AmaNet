# AmaNet - Online Extortion Management System

A Python application for managing online extortion cases, assessing risk levels, and generating official police reports.

## 🛠️ Installation
```bash
pip install Pillow arabic-reshaper python-bidi
```


## 🚀 How to Run

GUI Version:
```
python gui_app.py
```
CLI Version:
```
python main.py
```

## ⚠️ Disclaimer
​This project is developed strictly for educational and academic simulation purposes. It does NOT send data to real emergency services, police departments, or cybercrime units.
